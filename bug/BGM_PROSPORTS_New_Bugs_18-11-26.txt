--------------------------------------------------------------------------------
- Defect Page : Homepage
- Severity    : Medium
- Status      : Completed
- Affected    : main/platform/plugins/newsletter/src/Http/Requests/NewsletterRequest.php
                main/platform/themes/shofy/partials/shortcodes/newsletter/index.blade.php
- Steps to Reproduce:
  1. Log in to the website.
  2. Scroll to the bottom of the Homepage to the “Subscribe to our Newsletter” section.
  3. Enter an invalid email ID (e.g., a long string of numbers and special characters).
  4. Click the “Subscribe” button.
- Expected Result:
  The system should validate the email format and show an “Invalid email” error. The subscription should not be processed.
- Actual Result:
  The invalid email ID is accepted and a pop-up “You have subscribed to our newsletter” is displayed.
- Technical Root Cause:
  In `NewsletterRequest.php`, the email validation rule was:
  `'email' => ['required', 'email', ...]`
  It did not use `new EmailRule()` or `email:rfc`. Furthermore, client-side input in the newsletter form lacks the strict email regex or type validation, allowing arbitrary strings to trigger an optimistic success response or unhandled response.
- Recommended Fix:
  In `NewsletterRequest.php`, update the rule to:
  `'email' => ['required', 'string', 'email:rfc', new EmailRule(), ...]`
  Add HTML5 `type="email"` and client-side validation to the newsletter form.

BUG-031: Shipping Information – Coupon “Apply” loading spinner keeps rotating after invalid coupon message
--------------------------------------------------------------------------------
- Defect Page : Shipping Information / Checkout Coupon Section
- Severity    : Medium
- Status      : Completed
- Affected    : main/platform/plugins/ecommerce/resources/js/front/partials/discount.js
                main/platform/plugins/ecommerce/public/js/checkout.js
- Steps to Reproduce:
  1. Log in and add a product to the cart.
  2. Proceed to the “Shipping Information” page.
  3. Enter a coupon code that is not valid for the product (e.g. invalid code).
  4. Click “Apply”.
- Expected Result:
  The message “Coupon is not valid for this product” should be shown and the loading spinner should stop immediately, re-enabling the button so the user can try another coupon.
- Actual Result:
  The error message is displayed, but the loading spinner on the Apply button keeps rotating indefinitely.
- Technical Root Cause:
  In `discount.js`:
  Lines 71-72 add the spinner:
  `currentTarget.html('<span class="btn-spinner"></span>' + currentTarget.html())`
  In the `error: (data) => { ... }` AJAX callback (line 181):
  It calls `currentTarget.find('i').remove()`, but DOES NOT remove `.btn-spinner`!
  Because `.btn-spinner` is a `<span>` element (not an `<i>` tag), the spinner element remains permanently inside the button markup!
- Recommended Fix:
  In `discount.js`, line 181:
  Replace `currentTarget.find('i').remove()` with:
  `currentTarget.find('.btn-spinner, i').remove(); currentTarget.prop('disabled', false);`
  Also add a `complete:` callback to ensure the spinner is always removed regardless of response status.
